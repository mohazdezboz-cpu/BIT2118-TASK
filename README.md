# BIT 2118 – SCIENTIFIC COMPUTING

## Group Assignment: Tasks A to S

**Project Theme:** Mathematical Analysis, Program Modification, Interpretation and Real-World Applications

---

## 1. Project Overview

This repository contains the group assignment for **BIT 2118 – Scientific Computing**. The project focuses on applying scientific computing concepts, numerical methods, mathematical analysis, and Python programming to solve practical real-world problems.

The assignment covers Tasks A to S, demonstrating how computational techniques can be used to analyze data, solve mathematical problems, perform numerical calculations, and support decision-making in different fields.

Python libraries such as **NumPy and SciPy** are used to perform numerical computations efficiently and accurately.

## 2. Project Objectives

The main objectives of this assignment are:

- To apply scientific computing concepts in solving mathematical problems.
- To implement numerical methods using Python.
- To understand and modify existing programs by changing parameters.
- To analyze computational outputs and interpret their meanings.
- To demonstrate the application of scientific computing in real-world situations.
- To compare different numerical techniques based on accuracy and performance.

## 6. Methodology

Each task follows a systematic approach:

1. **Problem Identification:** Identify the mathematical or computational problem.
2. **Input Data:** Define the required variables, parameters and datasets.
3. **Mathematical Analysis:** Identify the formulas and numerical methods required.
4. **Implementation:** Develop the solution using Python.
5. **Program Modification:** Change selected parameters to observe their effects.
6. **Output Analysis:** Examine and interpret the computational results.
7. **Real-World Application:** Relate the results to a practical situation.

## 7. Expected Learning Outcomes

After completing this assignment, students should be able to:

- Understand the fundamentals of scientific computing.
- Perform numerical calculations using Python.
- Apply linear algebra and numerical methods.
- Solve linear and nonlinear equations.
- Perform interpolation, curve fitting and optimization.
- Solve ordinary differential equations.
- Use simulation techniques to analyze uncertainty and reliability.
- Interpret numerical results in practical applications.

This assignment demonstrates the importance of scientific computing in solving mathematical and real-world problems. Through Tasks A to S, the group applies different numerical techniques using Python and its scientific libraries.

The practical examples demonstrate how scientific computing can support decision-making in agriculture, finance, engineering, business, telecommunications, healthcare and information technology.
